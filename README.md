## Projects

**Activity management system (enterprise)**

A React frontend added to an existing ASP.NET MVC system. Most of it is one big data table with server-side pagination, filtering and sorting on multiple columns, and users can resize, reorder and hide columns. There are also forms with validation, all connected to the API. Data fetching and caching run through TanStack Query.

Built with React, TypeScript, TanStack Table, TanStack Query, shadcn/ui and Tailwind CSS.

**Customer portal for laser cutting workshops**

A web portal where customers sign up, log in, manage their profile and check their orders: material, dimensions, order type and specs. The workshop staff update the production stages, and the customer sees the progress on their order. Login and registration have some animated transitions.
